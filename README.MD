# Normalización y Gestión de Base de Datos - Gimnasio

Proyecto de normalización de datos (hasta la 3ª Forma Normal - 3NF), diseño de esquemas relacionales, implementación de DDL, DML, consultas avanzadas, procedimientos almacenados con control de errores y gestión de seguridad basada en roles (RBAC) para el sistema del gimnasio.
